## What I am building

### Banking Data Reliability Lab — in development

A public, reproducible data-engineering project demonstrating ingestion, validation, reconciliation, orchestration, observability, and recovery patterns for banking-style data. The project uses synthetic data only and is designed to show how pipelines remain trustworthy when inputs are late, duplicated, incomplete, or inconsistent.

Current focus:

- defining data contracts and quality checks;
- building idempotent Python/SQL transformations;
- orchestrating repeatable workflows with Airflow;
- recording failures, lineage, and reconciliation evidence;
- documenting trade-offs and reproducible tests.
